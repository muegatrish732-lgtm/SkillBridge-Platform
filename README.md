# SkillBridge-Platform
A digital learning platform designed to provide self paced skill development and progress tracking for students.

SkillBridge is a digital learning platform inspired by SDG 4: Quality Education. The platform helps students improve their digital skills through self paced learning modules and progress tracking.

## Features
- Learning Modules
- Progress Tracking
- User Dashboard
- Interactive Learning System

## Tools Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Purpose
This project was developed as an academic project for learning web development and database management.
